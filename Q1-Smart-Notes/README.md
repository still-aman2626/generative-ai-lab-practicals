

\# Q1 – Smart Note-Taking Application



\## Aim

To develop a Smart Note-Taking Application using HTML,

CSS and JavaScript with assistance from Generative AI.



\## Technologies

\- HTML5

\- CSS3

\- JavaScript

\- Browser localStorage



\## Features

\- Create, edit and delete notes

\- Search notes by title, content or tag

\- Organize notes using tags

\- Pin important notes

\- Persist notes across browser refreshes



\## How to Run

1\. Open this folder in VS Code.

2\. Open `index.html` in a web browser.

3\. Add a note and test the available features.



\## Storage

Notes are saved in the browser's localStorage.



\## Limitation

Notes are not synchronized between devices.
